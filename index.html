Mediklaud Deployment Tool

Personal project

Electron desktop application that automates build and packaging for 20+ client systems, replacing manual build and zip steps with a single tool.

Key details
  • Automates the release pipeline: git pull, React build, dotnet publish and IIS site/app-pool handling, packaging output into versioned, timestamped zip artifacts with live progress.
  • Builds and zips any client project without opening it in an IDE, with automatic detection of project folders and their current Git branch.
  • Manages multi-environment configuration by switching client-specific database connections and API URLs before a build and restoring the original files afterward.
